# Music Impressions

An agent skill for exploring a musical work through close listening, personal impressions, musical detail, and sourced context.

Begin with what the listener actually hears. Investigate a detail when it matters. Return to the music and leave room for the impression to change—or remain unfinished.

## Perspectives

The skill includes a listening companion, musician/analyst, dramaturg, performer/embodied listener, psychological interlocutor, historian, and philosophical/literary interlocutor. Use the perspective that serves the current question; they do not need to take turns.

Personal associations remain the listener's own. The skill distinguishes reported experience, inspected musical evidence, documented history, and proposed interpretation.

## Materials

A recording link, audio file, and sheet music are all optional. The agent can ask for useful materials or look for suitable sources without making them a prerequisite for the conversation.

The recording-and-score reference includes lessons from local stereo analysis and score matching: preserve the recording's clock, verify notation, allow overlapping pitches, compare alternatives, and treat filtered audio as a listening aid rather than proof of an interpretation.

An optional [AKOÚŌ reference](skills/music-impressions/references/akouo-listening.md) supports experiments with musical focus, bodily response, and changing attention. It combines attributed upstream ideas with a replay exercise developed in the listening conversation. No AKOÚŌ, OÍDA, or audio-model installation is required.

## Install and use

Copy [`skills/music-impressions`](skills/music-impressions/) into your agent's skills directory. For a personal Codex installation, use `~/.codex/skills/music-impressions`.

Example:

> Use $music-impressions to explore this piece with me, beginning with my impressions and finding useful recordings or scores when available.

You can request a particular perspective, such as “What would the dramaturg notice here?”
